# DSA-3 CO mapping
- CO1 — TextHack system: centralized query workspace and algorithm selection.
- CO2 — String algorithms: KMP and Rabin–Karp are implemented. Multi-pattern endpoint demonstrates matching by running KMP per pattern; it explicitly notes that this is not the optimized trie/failure-link Aho–Corasick implementation.
- CO3 — Advanced DP: Wagner–Fischer Edit Distance and LCS.
- CO4 — Network Flow: Edmonds–Karp with residual graph and source-side min-cut output.
- CO5 — Approximation: Vertex-Cover approximation demo.
- CO6 — Randomized/Parallel: Miller–Rabin demo and parallel independent text analysis.

The app also includes a general text-analysis endpoint with frequency-based keywords, a dictionary-based sentiment estimate, and extractive summary. These are deliberately labelled as lightweight methods, not as a trained AI model.
